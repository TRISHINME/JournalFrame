Personal Gemini Journal

Cognitive Bias & Sentiment Analyzer with Tenant-Isolated Storage

Architectural Summary

This client connects securely to the /api/journal/chat and /api/entries backend endpoints. All operations authenticate via Firebase ID tokens validated with firebase-admin, query with Gemini 2.5 Flash, and persist exclusively to user-scoped Firestore paths.

Model: gemini-2.5-flash Tenant Isolation: /journals/{uid}/entries Auth: Firebase ID Token Bearer
